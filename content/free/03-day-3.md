# День 3. Выкладываем в интернет

Сайт, который лежит в папке, никто не увидит. Сегодня у него появится ссылка.

## Шаг 1. Аккаунт на GitHub

**GitHub** — место, где хранят код. Бесплатно.

1. Зарегистрируйся на **github.com**. Имя пользователя выбирай аккуратное — оно будет в ссылке на твои сайты.
2. Включи двухфакторную защиту (Settings → Password and authentication). Это обязательно: аккаунт с сайтами клиентов не должен угнать никто.

## Шаг 2. Пусть агент сделает остальное

Напиши в Claude, в той же папке:

```text
Помоги выложить этот сайт на GitHub Pages.
Мой логин на GitHub: [логин].
Объясняй каждый шаг простыми словами. Если нужно что-то установить или войти в аккаунт — скажи, что именно сделать мне.
```

Агент скорее всего попросит установить **Git** и **GitHub CLI** и войти в аккаунт. Вход делаешь ты сам — пароли нейросети не передаём никогда.

Через пару минут сайт будет по адресу:

```text
https://[логин].github.io/my-first-site/
```

Если сразу не открылся — подожди 1–2 минуты, GitHub его собирает.

## Шаг 3. Проверь с телефона

Открой ссылку **на телефоне**, а не на компьютере. Именно так сайт увидит большинство людей. Пролистай до конца, нажми все кнопки.

Нашёл проблему — поправь в Claude и попроси: «Опубликуй изменения». Через минуту обновится и по ссылке.

## Что ты сделал за три вечера

- поставил агента и научился давать ему задачи;
- собрал сайт по своему плану, а не по шаблону;
- выложил его в интернет.

Именно этим путём делаются сайты, за которые платят. Разница только в деталях: дизайн, который не отличить от студийного, анимации, мобильная версия без единого огреха, и — главное — где взять человека, который заплатит.
