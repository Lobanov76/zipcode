# Вечер 3. Свой адрес в интернете

У каждого дома есть адрес, и у твоего сайта сегодня он тоже появится. Ссылка, которую можно отправить кому угодно, напечатать или превратить в QR-код.

## Шаг 1. GitHub — хранилище твоих сайтов

**GitHub** — сервис, где хранят код. Он же бесплатно показывает сайты по ссылке (это называется GitHub Pages).

1. Зарегистрируйся на **github.com**. Логин выбирай спокойный и короткий — он будет в адресе всех твоих сайтов: `логин.github.io`.
2. Сразу включи двухфакторную защиту: Settings → Password and authentication. Когда появятся сайты клиентов, аккаунт станет ценным.

## Шаг 2. Публикация

В папке `about-me` напиши агенту:

```text
Опубликуй этот сайт на GitHub Pages. Мой логин на GitHub: [логин].
Объясняй шаги простыми словами. Если нужно что-то установить или войти в аккаунт — скажи, что сделать мне, пароли я ввожу сам.
В конце дай ссылку и проверь, что она открывается.
```

Скорее всего агент попросит установить Git и GitHub CLI и один раз войти в аккаунт через браузер. Через пару минут сайт будет по адресу вида:

```text
https://логин.github.io/about-me/
```

Если сразу показывает ошибку 404 — подожди минуту-две, GitHub собирает страницу.

## Шаг 3. QR-код

```text
Сделай QR-код на ссылку моего сайта: файл qr.png, чёрный на белом, 1000×1000 px, с белым полем вокруг.
```

QR пригодится на визитке, на стикере на ноутбуке, на слайде презентации. И это просто приятно — навести камеру и увидеть свой сайт.

## Шаг 4. Покажи трём людям

Отправь ссылку трём знакомым и задай **один вопрос**: «Что тебе здесь непонятно или неудобно?» Не «как тебе?» — на такой вопрос все отвечают «норм».

Ответы перешли агенту: «Мне написали вот это — поправь». Опубликуй изменения: «Обнови сайт на GitHub Pages».

## Что ты умеешь после трёх вечеров

- ставить агенту задачи и вести его правками;
- выбирать стиль, а не соглашаться на первый вариант;
- проверять сайт глазами посетителя;
- выкладывать работу в интернет по своему адресу.

Это тот же цикл, по которому делаются сайты на заказ. Разница — в уровне дизайна, движении на странице, мелочах мобильной версии и в том, откуда взять первого клиента. Этим и занимается курс участников.

**Задание:** оставь ссылку на свою визитку в комментариях под закреплённым постом канала zipcode. Самые интересные работы разберём в канале.
