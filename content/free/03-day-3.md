# Вечер 3. Свой адрес в интернете

**После этого вечера ты:**
- выложил сайт в интернет по своей ссылке — бесплатно;
- сделал QR-код на свой сайт;
- получил первые отзывы и поправил сайт по ним.

У каждого дома есть адрес. Сегодня он появится и у твоего сайта: ссылка, которую можно отправить кому угодно, напечатать или превратить в QR-код. Финал марафона — погнали.

## Шаг 1. GitHub — хранилище твоих сайтов

**GitHub** — сервис, где хранят код. Он же бесплатно показывает сайты по ссылке (это называется GitHub Pages).

1. Зарегистрируйся на **github.com**. Логин бери короткий и спокойный — он будет в адресе всех твоих сайтов: `логин.github.io`.
2. Сразу включи двухфакторную защиту: Settings → Password and authentication. Когда появятся сайты клиентов, аккаунт станет ценным.

## Шаг 2. Публикация

В папке `about-me` напиши агенту:

```text
Опубликуй этот сайт на GitHub Pages. Мой логин на GitHub: [логин].
Объясняй шаги простыми словами. Если нужно что-то установить или войти в аккаунт — скажи, что сделать мне, пароли я ввожу сам.
В конце дай ссылку и проверь, что она открывается.
```

Скорее всего агент попросит установить Git и GitHub CLI и один раз войти через браузер. Через пару минут сайт будет по адресу вида `https://логин.github.io/about-me/`. Показывает 404 — подожди минуту-две, GitHub собирает страницу.

## Шаг 3. QR-код

```text
Сделай QR-код на ссылку моего сайта: файл qr.png, чёрный на белом, 1000×1000 px, с белым полем вокруг.
```

Наведи камеру телефона — и вот он, твой сайт. Кайф, согласись.

## Шаг 4. Покажи трём людям

Отправь ссылку трём знакомым и задай **один вопрос**: «Что тебе здесь непонятно или неудобно?» Не «как тебе?» — на это все отвечают «норм».

Ответы перешли агенту: «Мне написали вот это — поправь». И: «Обнови сайт на GitHub Pages».

## Задание

Оставь ссылку на свою визитку в комментариях под закреплённым постом канала zipcode. Самые интересные работы разберём.

## Что ты теперь умеешь

Марафон закрыт. Ты умеешь:
- ставить агенту задачи и вести его правками;
- выбирать стиль, а не соглашаться на первый вариант;
- проверять сайт глазами посетителя;
- выкладывать работу в интернет по своему адресу.

Это тот же цикл, по которому делаются сайты на заказ. **Но между «я умею сделать сайт» и «мне за сайт заплатили» — пропасть.** И она не в коде:

- **Дизайн, от которого «вау»**, а не «норм» — урок 2.1.
- **Анимации и свой «герой»**, которые делают сайт дорогим — уроки 2.2–2.4.
- **Где взять первого клиента** и что ему написать, чтобы ответил, — урок 2.5.
- **Как назвать цену и взять предоплату** без дрожи в голосе — урок 2.6.
- Плюс ролики, которые залетают, и ИИ-боты, за которые бизнес платит каждый месяц.

Всё это — **zipcode club, $19 в месяц**: 18 уроков, готовые промпты под каждый шаг и чат, где разбирают твои работы. Это меньше, чем стоит один самый простой сайт для клиента. Первый заказ окупит год подписки.

Ты уже доказал себе, что можешь. Не останавливайся на «норм».

**Открой вкладку «Доступ» в приложении → «Оформить» — и продолжаем с урока 1.1.**
